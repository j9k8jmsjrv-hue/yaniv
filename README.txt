【ヤニブ アプリ版(ホーム画面・オンライン対戦対応)】

このzipの中身をWebサイトとして公開すると、そのURLひとつで
・ホーム画面に追加して全画面・横画面で遊べる
・友達とオンライン対戦(ルーム戦)ができる(登録・ログイン不要)
・CPU戦は一度開けば圏外(オフライン)でも遊べる
ようになります。対戦履歴・成績は、それぞれのスマホに保存されます。

━━━━━━━━━━━━━━━━━━━━
■ スマホだけで公開する(GitHub Pages・無料・URLずっと固定)
━━━━━━━━━━━━━━━━━━━━
 1. スマホのブラウザで https://github.com を開き、無料アカウントを作る
 2. 右上の「＋」→「New repository」
    名前: yaniv(なんでもOK) / 「Public」を選ぶ →「Create repository」
 3. 「uploading an existing file」をタップ
 4. このzipを「ファイル」アプリでタップして展開(フォルダになります)
    → 中のファイル7つを全部選んでアップロード →「Commit changes」
 5. リポジトリの「Settings」→「Pages」
    Branch を「main」「/(root)」にして「Save」
    (Settingsが見つからないときは、ブラウザの「デスクトップ用Webサイトを表示」)
 6. 1〜2分で次のURLで開けます
    https://(あなたのユーザー名).github.io/yaniv/
 7. このURLをLINEグループのアナウンスに固定

 ■ 更新するとき(URLも履歴もそのまま)
  リポジトリで「Add file」→「Upload files」→ 新しいzipの中身を全部アップロード
  →「Commit changes」(同じ名前のファイルは上書きされます)

━━━━━━━━━━━━━━━━━━━━
■ パソコンがある場合(Netlify・無料)
━━━━━━━━━━━━━━━━━━━━
 1. https://app.netlify.com/drop にこのzipをドラッグ&ドロップ
 2. 「claim / Sign up」で無料登録してサイトを自分のものにする
 3. Site configuration → Change site name で好きなURLに
 ※スマホからのアップロードはうまくいかないことが多いので、スマホだけならGitHub Pagesを使ってください

━━━━━━━━━━━━━━━━━━━━
■ 友達と対戦する
━━━━━━━━━━━━━━━━━━━━
 1. ホストが「ルーム戦」→「ルームを作る」→ 人数・試合数・持ち時間 →「ルームを作る」
 2. 同じURLを開いている人の「ルーム戦」画面に「開いているルーム」として表示されるので、
    友達は「参加 ▶」をタップするだけで入れます(「コードで参加」→ 4桁 でも入れます)
 3. 全員そろったらホストが「ゲーム開始」(足りない席はCPU)
 ・対戦中は画面が自動で消えないようにしています
 ・LINEの通知を見に行くなどで一瞬アプリを離れて接続が切れても、
   45秒以内に戻れば自動でつながり直して続けられます(席はそのまま)
 ・45秒たっても戻らない人は「途中退出」扱いになり、人数を減らして続行します
 ※ネット接続が必要です。電波の悪い所ではつながりにくいことがあります

━━━━━━━━━━━━━━━━━━━━
■ フレンド(ID検索)
━━━━━━━━━━━━━━━━━━━━
 ☰ →「フレンド」の一番上に「あなたのID」(8桁)が出ます。
 友達のIDを「ID検索」に入れて検索 →「フレンド申請」→ 相手が「承認」でフレンドになります。
 ・相手がオフラインのときは「申請を予約」しておくと、相手がアプリを開いたときに届きます
   (あなたもアプリを開いている間に限ります)
 ・届いた申請は「あとで」を押しても、フレンド画面の「届いた申請」に残ります
 ・フレンドがルームにいるときは「参加」、自分がルームにいるときは「招待」が押せます
 ・スマホを替えたときは「引き継ぎコード」で移すと、IDもそのまま引き継がれます

━━━━━━━━━━━━━━━━━━━━
■ データ(名前・ID・履歴)の保存場所
━━━━━━━━━━━━━━━━━━━━
 データはサーバーではなく、開いた場所ごとに保存されます。
 iPhoneでは「Safari」「ホーム画面のアプリ」「LINEの中」はそれぞれ別の保存場所です。
 ・LINEのリンクをタップすると、自動でSafari(Androidは標準ブラウザ)で開くようにしています
 ・はじめての場所で開くと「はじめまして」画面が出ます。前に遊んだデータがあるときは、
   データがある方で ☰ → その他 →「引き継ぎコードをコピー」→ 新しい方に貼り付けて「引き継ぐ」
   (名前・ID・フレンド・履歴・成績がそのまま移ります)
 ・遊ぶ場所はひとつに決めておくのがおすすめです

━━━━━━━━━━━━━━━━━━━━
■ 対戦履歴を消えにくくするために
━━━━━━━━━━━━━━━━━━━━
 LINEの中で開いたら「…」→「ブラウザで開く」を選び、
 iPhone : Safari → 共有ボタン → 「ホーム画面に追加」
 Android: Chrome → メニュー(︙) → 「ホーム画面に追加」/「アプリをインストール」
 ホーム画面から開くと、ブラウザの自動整理で履歴が消えにくくなります。
 スマホを替えるときは「☰ → その他 → 引き継ぎコードをコピー」で移せます。
